# 📝 Task Manager API (Docker + Node.js + PostgreSQL)

A simple backend project demonstrating full-stack backend skills using:

- **Node.js** and **Express** for building RESTful APIs
- **PostgreSQL** as the database
- **Docker Compose** to containerize the backend and database

---

## 📌 What this project includes:

- ✅ A fully functional **CRUD API** (`Create`, `Read`, `Update`, `Delete`)
- ✅ Built with **Node.js + Express** backend
- ✅ Database integration with **PostgreSQL** using SQL queries
- ✅ Environment-based configuration using `.env`
- ✅ Complete **Docker setup** with multi-container architecture:
  - Backend container
  - PostgreSQL DB container
- ✅ Code tested using both:
  - 🧪 Command line (`curl`)
  - 🧪 API Client (Thunder Client in VS Code)
